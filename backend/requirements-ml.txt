# Kept SEPARATE from requirements.txt on purpose: these are heavy (torch pulls
# hundreds of MB) and only the *runtime* matching path needs them. The unit
# tests inject fake embedders, and app.matching.embedder lazy-imports
# sentence_transformers, so CI and the normal test run stay torch-free and fast.
#
# Install for real semantic matching / building company_profile embeddings:
#   pip install -r requirements-ml.txt
# (locally add the project's SSL workaround:
#   --trusted-host pypi.org --trusted-host files.pythonhosted.org)
#
# Docker/CI note: on Linux, `torch` defaults to the CUDA build (~2 GB). For a
# CPU-only image pin the CPU wheel, e.g.:
#   --extra-index-url https://download.pytorch.org/whl/cpu
# First model use downloads paraphrase-multilingual-MiniLM-L12-v2 (~470 MB) via
# Hugging Face; the embedder injects truststore so AV/proxy SSL inspection
# doesn't block it.
